### Yes

If AI is supposed to be doing a better job at coding, then what are humans reviewing in it? 

I don't understand why I need to spend extra time and effort just to read output from coding agents that humans aren't supposed to write. 

I feel a industry wide scam is telling us to do code reviews. Because in reality we can't do manual code reviews. The AI-generated code does not express the intent and reasoning made to arrive to that code output, and all of a sudden it becomes our job to decipher and review code.

Either write the code yourself and review it by others or just accept the AI code as it is and move on.
